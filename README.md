# Puzzlebook

A personal, fully-offline Android puzzle game with two logic modes served as
one endless difficulty track:

- **Snap** — draw a single line through every cell, hitting the numbers in
  order (a numbered Hamiltonian path).
- **Shikaku** — carve the grid into rectangles whose areas match their clue
  numbers.

No backend, no accounts, no ads. 640 pre-generated, uniqueness-checked
puzzles ship in the app as JSON banks; progress, streak, and stats live in
local MMKV storage.

> ⚠️ **This app cannot run in Expo Go.** Skia, MMKV, Reanimated, and
> gesture-handler are native modules — you need a custom dev build (see
> below).

## Running on a device

```bash
npm install

# Option A: local build (needs Android SDK + a connected device/emulator)
npx expo run:android

# Option B: EAS dev client / sideload APK (needs a free Expo account)
npx eas build --profile development --platform android   # dev client
npx eas build --profile preview --platform android       # standalone APK
```

After installing a dev client, `npm start` serves the JS bundle.

## Scripts

| Command | What it does |
|---|---|
| `npm test` | Jest unit tests for validators, solvers, generators |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run bank` | Regenerates `src/data/*-bank.json` (640 puzzles, ~10s) |
| `npm run sfx` | Re-synthesizes the WAV sound effects in `assets/sfx` |
| `npm run lint` | ESLint via `expo lint` |

The generators in `tools/` run on a computer with `tsx` — never on the
device. Every puzzle is checked for **solution uniqueness** (a counting
solver caps at 2) before it enters a bank, and banks are deterministic for
a given seed (`tools/build-bank.ts`).

## Architecture

```
tools/*.ts  ──(generate + uniqueness-check)──▶  src/data/*-bank.json (bundled)

app/* (expo-router screens)
   └─ src/puzzles/loader.ts  → picks next unsolved puzzle on the level track
       └─ src/ui/{snap,shikaku}/*Board.tsx  → Skia canvas + gestures
           └─ src/puzzles/*/validate.ts     → pure-TS rules (unit-tested)
               └─ src/state/*               → MMKV: progress, streak, stats
```

The puzzle logic (`src/engine`, `src/puzzles/*/types|validate|hint`) is
pure TypeScript with zero React/native imports, shared between the app and
the offline generators, and covered by `__tests__/`.

### The global track

Levels 1–640 alternate Snap (odd) and Shikaku (even) and climb three
difficulty tiers:

| Levels | Tier | Snap | Shikaku |
|---|---|---|---|
| 1–200 | easy | 5×5 | 5×5 |
| 201–440 | medium | 6×6 | 7×7 |
| 441–640 | hard | 7×7 | 9×9 |

Solving advances the level pointer; the header shows `{streak}-{solves today}`.
